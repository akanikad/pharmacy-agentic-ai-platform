# Buy vs Build Analysis

## Decision framework

Score each option on:

- capability fit
- integration effort
- security/compliance
- operational burden
- vendor lock-in
- TCO
- time to value
- scalability
- talent availability

## Example

### Foundation model
**Recommendation: Buy / managed**

Reason: model training is not the differentiating PBM capability. Focus engineering
on domain workflows, grounding, integration, governance, and user experience.

### Domain workflow
**Recommendation: Build**

Reason: authorization and claims workflow rules are domain-specific and should
remain controlled by enterprise application services.
